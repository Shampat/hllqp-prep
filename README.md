# HLLQP Prep Canada

A professional offline-first Android application for preparing for the Canadian HLLQP (Harmonized Life License Qualification Program) examination.

## Technology

- Kotlin
- Jetpack Compose
- Material 3
- Room Database
- MVVM
- Clean Architecture
- Git
- GitHub

## Project Goals

- Offline-first
- Commercial quality
- Google Play ready
- Future iOS support
- Canadian terminology only
